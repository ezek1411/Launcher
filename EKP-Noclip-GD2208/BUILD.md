# Compilation rapide

Dans PowerShell, avec Geode CLI et le SDK configurés :

```powershell
cd EKP-Noclip-GD2208
geode build
```

Le paquet produit sera un fichier `.geode` dans le dossier de build ou le dossier de sortie indiqué par la CLI.

Cette base ne contient pas de hook Noclip actif. Il faut valider les bindings Geometry Dash 2.208 avant toute modification du gameplay.
